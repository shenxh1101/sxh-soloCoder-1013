# 像素体育俱乐部 (Pixel Sports Club)

一款复古像素风的体育俱乐部经营游戏。

## 游戏特色

- 🎮 **6个游戏场景**：主菜单、训练馆、球员宿舍、比赛日、转会市场、荣誉墙
- ⚽ **完整的赛季系统**：联赛、杯赛、升级降级
- 🏋️ **训练系统**：力量、速度、配合、恢复四种训练
- 📊 **球员管理**：疲劳、伤病、士气、合同系统
- ⚔️ **战术系统**：5种阵型、进攻/防守/节奏战术调整
- 💰 **转会市场**：买卖球员、青训提拔、预算管理
- 🏆 **成就系统**：16种奖杯等你解锁

## 技术栈

- Electron 28.x - 桌面应用框架
- HTML5 Canvas - 像素艺术渲染
- 原生 JavaScript - 游戏逻辑
- localStorage - 游戏存档

## 运行方式

### 方式一：直接在浏览器中运行（推荐用于测试）

1. 进入项目目录
2. 启动本地服务器：
   ```bash
   # 使用 Python
   python -m http.server 8080
   
   # 或使用 Node.js
   npx http-server
   ```
3. 浏览器访问 `http://localhost:8080`

### 方式二：Electron 桌面应用

```bash
# 安装依赖
npm install

# 启动应用
npm start

# 打包发布
npm run build
```

## 游戏玩法

### 1. 开始新游戏
- 从乙级联赛开始，目标是晋级甲级联赛并夺冠
- 初始球队有13名球员和500万预算

### 2. 训练馆
- 选择训练类型：力量、速度、配合、恢复
- 调整训练强度：低/中/高
- 点击球员进行针对性训练
- 全体休息可恢复所有球员体力

### 3. 球员宿舍
- 查看所有球员状态（伤病、疲劳、合同）
- 对合同即将到期的球员进行续约
- 按条件筛选球员

### 4. 比赛日
- 选择首发11人和5名替补
- 选择阵型：4-3-3、4-4-2、3-5-2、5-3-2、4-2-3-1
- 调整进攻和防守倾向
- 观看实时比赛进程，可暂停和加速
- 比赛中可调整战术和换人

### 5. 转会市场
- 查看市场上的可用球员
- 出售队中不需要的球员
- 签约新球员增强实力
- 提拔青训球员

### 6. 荣誉墙
- 查看已解锁的奖杯
- 按类型筛选：联赛、杯赛、成就、个人、青训
- 查看奖杯解锁条件和获得时间

## 游戏机制

### 球员属性
- **力量**：影响对抗、射门、防守
- **速度**：影响突破、回追、反击
- **配合**：影响传球、团队协作
- **疲劳**：过高会影响表现，增加受伤风险
- **士气**：影响比赛发挥
- **伤病**：受伤期间无法出场

### 比赛系统
- 实时模拟比赛进程
- 战术调整影响攻防效率
- 球员状态影响比赛表现
- 主客场优势加成

### 财政系统
- 每周收入：门票 + 赞助
- 每周支出：球员薪水
- 转会收入/支出
- 赛季奖金
